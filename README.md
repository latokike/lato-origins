# __Notice__

[Lato Origins](https://www.curseforge.com/minecraft/mc-mods/lato-origins) has been abandoned since late 2022. Some of you may not know, but Lato Origins used code from [Extra Origins](https://www.curseforge.com/minecraft/mc-mods/lato-origins) to power itself.

This is because, originally, Lato Origins was just a modification to the Extra Origins mod - a little datapack I made for myself after I learned of the [Origins](https://www.curseforge.com/minecraft/mc-mods/origins) mod. When I found out how to turn Lato Origins into a standalone mod, I did so, because the concept of having my own Origins addon appealed to me. At the time, I did not realize that Extra Origins' code was licensed under GNU GPL-3.0 or what that entailed, and as such I naively licensed my own mod under MIT. This is in violation of the GPL-3.0 license; Lato Origins should've also been licensed as GPL-3.0, but it was not. As such, I've decided to withdraw my support from this project. Additionally, the fact that its code was directly copied from Extra Origins has caused several issues with when using both mods together during this project's lifetime.

I apologize to everyone who has enjoyed this mod and hoped for an updated version of it that would be compatible with newer versions of Minecraft and Fabric.
